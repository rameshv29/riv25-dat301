# pgvector KB MCP Server

PostgreSQL pgvector Knowledge Base MCP Server for DAT301 Workshop.

This MCP server provides AI-powered document search capabilities using PostgreSQL with pgvector extension.

## Features

- Document ingestion and storage
- Semantic search using vector embeddings
- PostgreSQL with pgvector integration
- MCP protocol support

## Usage

The server is deployed as part of the DAT301 workshop infrastructure and provides tools for:

- `ListDocuments`: List available documents
- `QueryKnowledgeBase`: Search documents using semantic similarity
- `GetDocument`: Retrieve specific documents
- `IngestDocument`: Add new documents to the knowledge base
